# Tommy, AI As Real As It Gets

Hi, I’m Tommy Poole. I’m a learner and builder, passionate about helping people. I work at the intersection of healthcare, artificial intelligence, and the human side of change. This is my personal portfolio and a place to share the books, films, albums, and podcasts I keep coming back to.

## Explore the site

- **Experience** shares how I help healthcare teams turn complex problems into practical solutions.
- **On Repeat** pairs my notes on films, music, and podcasts with looping dot animations.
- **The Bookshelf** lets you pick a spine to see the cover and read why the book stuck with me.

## Run locally

Open [`index.html`](index.html) in a browser. The site uses plain HTML, CSS, and JavaScript. The portrait, book covers, and spines are embedded in the file, so there’s no install or build step.

To serve it over HTTP, run this from the folder containing `index.html`:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Publish with GitHub Pages

Put `index.html` in the repository root. In **Settings → Pages**, choose **Deploy from a branch**, then select the branch containing the file and **/ (root)**. Save the settings. Future pushes to that branch will update the site. [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
